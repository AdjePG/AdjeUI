# AdjeUI.Demo

The live demo: one page with every AdjeUI component and prop, by category, built
with Vite straight from `../AdjeUI.LibraryCore`.

```bash
npm run demo   # from the repo root, http://localhost:4400 (PORT=… for another port)
```

Every new public component or prop gets a block here (`sections/<Category>.tsx`).
Later this may become a Docusaurus site with AdjeUI's own look.
